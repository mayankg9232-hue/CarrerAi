# AI Copilot pictogram

The Copilot launchers use the user-selected **Search engine** animated icon,
Flaticon asset **18559549**:

- Source: https://www.flaticon.com/free-animated-icon/search-engine_18559549
- Animated original: https://cdn-icons-gif.flaticon.com/18559/18559549.gif
- Still original: https://cdn-icons-png.flaticon.com/512/18559/18559549.png

Both files are stored unmodified and served locally. Their artwork remains under
the source provider's license, separate from the repository's code license.
The Career Agent view includes a visible link to the source attribution.

The PNG is shown at rest and for reduced-motion preferences. Hovering or
keyboard-focusing either Copilot launcher loads the GIF as an overlay, retaining
the PNG beneath it as a fallback. The GIF is not requested for reduced motion.
No external animation player or JavaScript dependency is needed.
